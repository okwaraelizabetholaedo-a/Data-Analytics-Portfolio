# Healthy diet and calorie intake

**Tools:** Excel, PivotTables, Slicers, Power Query

*How do calorie balance, activity, diet type and demographics relate to health status?*

## About this project

A one-sheet interactive Excel dashboard built on derived fields: BMI category, calorie balance, calorie status, macronutrient calories and percentages, and age groups.

## Key findings

- The sedentary group had the highest average surplus (+230.50 kcal).
- Observed obesity rate: male 20.02%, female 15.80%.
- Average BMI stayed close to 26 across the six diet types, so diet label alone did not explain health differences.

> Observational data. BMI does not directly measure body fat, and the dataset has no time dimension.
