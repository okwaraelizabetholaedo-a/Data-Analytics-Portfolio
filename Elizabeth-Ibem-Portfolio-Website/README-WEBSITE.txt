# Elizabeth Ibem Portfolio Website

This folder contains the website files for the GitHub Pages version of Okwara Elizabeth Ibem's data analytics portfolio.

## Files
- `index.html` — website structure and content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation, scroll progress and footer year

## Publish on GitHub Pages

1. Open the `Data-Analytics-Portfolio` repository.
2. Upload `index.html`, `style.css`, and `script.js` to the top level of the `main` branch.
3. Keep the existing Markdown project files and `ASSETS` folder.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then click **Save**.
7. Wait for GitHub to publish the site.

The project URL should be:

https://okwaraelizabetholaedo-a.github.io/Data-Analytics-Portfolio/

GitHub Pages publishes a static site from a repository, and an `index.html` at the top level of the selected publishing source is the standard entry point.
