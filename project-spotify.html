01 / Overview

About the project

This project explores Spotify streaming data to understand which artists and tracks perform strongly, how streaming activity varies across the dataset and what patterns can be identified from listener behaviour. The analysis transforms raw streaming records into interactive and easy-to-understand insights.

03 / Insights

Key Findings

Streaming performance varies considerably across artists and tracks, allowing high-performing content to be identified from the dataset.
Track and artist-level analysis provides different views of music performance and helps reveal patterns that may not be visible from overall streaming totals alone.
Interactive visual analysis makes it easier to compare streaming behaviour and identify trends across the available Spotify data.
The findings describe patterns observed within the analysed dataset and should not be interpreted as representing all Spotify listeners or the entire music industry.
