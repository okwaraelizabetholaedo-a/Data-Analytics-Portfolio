# Spotify streaming insights

**Tools:** Excel, Slicers, Data cleaning

*Which tracks, genres and countries drive streams, and which songs are fading?*

## About this project

An Excel dashboard on streaming performance across artists, genres and countries, with slicers for exploring the data.

## Key findings

- SWIM was the most streamed track.
- About 30% of tracks were gaining streams, so a few tracks dominate while many struggle to keep growing.
- Takeaway: popularity does not always mean sustainability.
